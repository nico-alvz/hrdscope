# Summary

About half of high-grade serous ovarian carcinomas carry homologous recombination deficiency (HRD) and benefit from PARP inhibitors, but the genomic assays that establish HRD status are expensive and unavailable in most health systems. `hrdscope` is an MIT-licensed Python package that turns the haematoxylin and eosin (H&E) slide every patient already has into a calibrated triage signal. It (1) computes the three genomic scar scores (HRD-LOH, NtAI, LST) from open allele-specific copy-number segments and releases labels for 555 TCGA-OV patients, (2) tiles and embeds whole-slide images with open-weight pathology foundation models, (3) trains and evaluates attention-based multiple-instance models on fixed patient-level splits with nested hyper-parameter search, and (4) predicts on new slides with an ensemble, an uncertainty estimate and an attention heatmap. Everything runs on one 8 GB consumer GPU.

# Statement of need

Published HRD-from-H&E models [@bergstrom2024; @zafar2025; @wang2026] report useful accuracy but none can be installed and run by a third party under a permissive license with downloadable weights, and each uses its own private label table and threshold (33, 42 or 63), so results cannot be compared. `hrdscope` provides the missing open label table, the benchmark protocol, and a deployable tool, so that laboratories, method developers and reviewers work from the same open baseline.
